## Описание

Консольная утилита для подписания файлов и проверки ЭЦП с использованием алгоритма **ГОСТ Р 34.10-2012**.  
Алгоритм реализован с нуля на Python 3.13 — все операции с точками эллиптических кривых реализованы вручную. Для вычисления хеша по **ГОСТ Р 34.11-2012** использовалась библиотека **pygost**.

---

## Структура проекта

```
./
├── signatures/      — Директория подписанных документов
├── logs/            — Директория логов утилиты
├── main.py          — точка входа; разбор аргументов CLI, загрузка конфигурации, запуск шифрования
├── ecp.py           — реализация алгоритма подписания документа и проверки подписи

├── handler.py       — функции чтения и записи файлов (текстовый и бинарный режимы)
├── .env             — файл конфигурации (параметры эллиптической кривой, закрытый ключ d, режим, уровень логирования и др.)
├── .env.example     — пример файла конфигурации с описанием всех параметров
└── .gitignore       — исключения для системы контроля версий
```

## Установка и запуск

**1. Клонировать репозиторий:**
```bash
git clone <https://github.com/kartowe4ka03/gost_r_34.10-2012.git>
cd <project-folder>
```

**2. Создать файл конфигурации:**
```bash
cp .env.example .env
```

**3. Заполнить `.env`** — обязательно задать `параметры эллиптической кривой`.

**4. Запустить подпись документа:**
```bash
python main.py -f input.txt -g
```

**5. Запустить проверку подписи:**
```bash
python main.py -f input.txt -v --sign .\signatures\input.txt\input.txt.sig --metadata .\signatures\input.txt\METADATA.json
```

## Аргументы командной строки

| Аргумент | Описание |
|---|---|
| `-f`, `--file PATH` | Путь к входному файлу (по умолчанию из `.env`) |
| `-g`, `--generate` | Выполнить подписание документа |
| `-v`, `--verify` | Выполнить проверку подписи |
| `--bits 256/512` | Размер хеш-кода (по умолчанию из `.env`) |
| `--no-overwrite` | Запретить перезапись выходного файла |
| `--sign PATH` | Путь к файлу ЭЦП для документа |
| `--metadata PATH` | Путь к метаданным ЭЦП для документа |
| `-h`, `--help` | Справка |

Аргументы CLI имеют **приоритет** над значениями из `.env`.

## Конфигурация (`.env`)

```dotenv
# ─── Параметры эллиптической кривой ───────────────────────────────────────────────
# Используются только для подписания, для проверки данные извлекаются из JSON
# a, b - коэффициенты эллиптической кривой
# p - модуль эллиптической кривой, обязательно простое число
# q - порядок подгруппы эллиптической кривой, обязательно простое число
# P - образующая точка подгруппы порядка q. Формат записи: (x, y)
# d - закрытый ключ подписи, 0 < d < q
a=
b=
p=
q=
POINT=
d=

# ─── Размер хеш-кода ─────────────────────────────────────────────────────────────
# Алгоритм ГОСТ Р 34.11-2012 (Streebog)
# Возможные значения: 256 или 512 бит
HASHSIZE=256

# ── Файлы ─────────────────────────────────────────────────────
# Используются, если не переданы аргументы -f / --file через CLI.
DEFAULT_INPUT_FILE=initial_text.txt

# ── Логирование ───────────────────────────────────────────────
# Уровень: DEBUG, INFO, WARNING, ERROR, CRITICAL
LOG_LEVEL=INFO

# ── Поведение ─────────────────────────────────────────────────
# Режим по умолчанию при отсутствии -g/-b: generate или verify
APP_MODE=generate

# Разрешить перезапись выходного файла: true или false
OVERWRITE_OUTPUT=true
```

## Особенности работы с утилитой

### Подписание документа
Может быть вызвано без CLI-аргументов. В таком случае все параметры будут взяты из `.env`. CLI-аргументы `--bits` и `--no-overwrite` являются **необязательными**.

```
python .\main.py
```

Подписанные документы сохраняются по пути (Пример для файла `initial_text.txt`):

```
./
├── signatures/
    ├── initial_text.txt/
        ├── initial_text.txt     — Исходный подписываемый документ
        ├── initial_text.txt.sig — ЭЦП для initial_text.txt
        └── METADATA.json        — Метаданные:  параметры эллиптической кривой, длина хеш-кода, открытый ключ проверки.
```


### Проверка ЭЦП
Может быть вызвано без CLI-аргументов. В таком случае все параметры будут взяты из `.env`. CLI-аргументы `--sign` и `--metadata` являются **обязательными** для этого режима.

```
python .\main.py
```
