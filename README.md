# AES Encryption Tool

Практическая работа № 2 по дисциплине **«Криптографические методы защиты информации»**  
Тема: **«Электронная подпись»**

**Преподаватели:** Евсютин Олег Олегович, Мельман Анна Сергеевна

---

## Описание

Консольная утилита для подписания файлов и проверки ЭЦП с использованием алгоритма **ГОСТ Р 34.10-2012**.  
Алгоритм реализован с нуля на Python 3.13 — все операции с точками эллиптических кривых реализованы вручную. Для вычисления хеша по **ГОСТ Р 34.11-2012** использовалась библиотека **pygost**.


## Установка и запуск

**1. Клонировать репозиторий:**
```bash
git clone <https://github.com/kartowe4ka03/python_console_aes.git>
cd <project-folder>
```

**2. Создать файл конфигурации:**
```bash
cp .env.example .env
```

**3. Заполнить `.env`** — обязательно задать `AES_KEY` и (для CTR) `AES_IV`.

**4. Запустить шифрование:**
```bash
python main.py -e -f input.txt -o output.bin
```

**5. Запустить расшифрование:**
```bash
python main.py -d -f output.bin -o result.txt
```

## Аргументы командной строки

| Аргумент | Описание |
|---|---|
| `-e`, `--encrypt` | Выполнить шифрование |
| `-d`, `--decrypt` | Выполнить расшифрование |
| `-f`, `--file PATH` | Путь к входному файлу (по умолчанию из `.env`) |
| `-o`, `--output PATH` | Путь к выходному файлу (по умолчанию из `.env`) |
| `-m`, `--mode MODE` | Режим AES: `ECB`, `CBC`, `CFB`, `OFB`, `CTR` (по умолчанию из `.env`) |
| `--no-overwrite` | Запретить перезапись выходного файла |
| `-h`, `--help` | Справка |

Аргументы CLI имеют **приоритет** над значениями из `.env`.

```dotenv
# ── Шифрование ────────────────────────────────────────────────

#   32 символа (32 байта) → AES-256
# Ключ обрабатывается в коде в кодировке utf-8, с другими кодировками

AES_KEY=

# Синхропосылка (Initializing Value) в виде строки
#   CBC, OFB, CFB: 16 символов (16 байт)
#   CTR: 8 символов (8 байт) — достраивается до 16 байт автоматически
# Игнорируется в режиме ECB.
# Синхропосылка обрабатывается в коде в кодировке utf-8, с другими кодировками

# Размер ключа в битах: 128, 192 или 256
AES_KEY_SIZE=256

# Режим шифрования: ECB, CBC, CFB, OFB, CTR
AES_MODE=ECB

# Схема дополнения (только для ECB, CBC): ZERO, ONE-ZERO, UNIVERSAL
AES_PADDING=ONE-ZERO

# ── Файлы ─────────────────────────────────────────────────────
DEFAULT_INPUT_FILE=initial_text.txt
DEFAULT_OUTPUT_FILE=edited_text.txt
FILE_ENCODING=utf-8

# ── Логирование ───────────────────────────────────────────────
# Уровень: DEBUG, INFO, WARNING, ERROR, CRITICAL
LOG_LEVEL=INFO

# ── Поведение ─────────────────────────────────────────────────
# Режим по умолчанию при отсутствии -e/-d: encrypt или decrypt

# Разрешить перезапись выходного файла: true или false
```

## Реализованные режимы шифрования

### ECB (Electronic Codebook)
Каждый 16-байтовый блок открытого текста шифруется **независимо** одним и тем же ключом.

```
P₁ → AES_enc(K) → C₁
P₂ → AES_enc(K) → C₂
...
```

- **Дополнение обязательно** (ZERO / ONE-ZERO / UNIVERSAL).
- Одинаковые блоки открытого текста дают одинаковые блоки шифртекста.

### CTR (Counter Mode)
Потоковый режим: гамма генерируется шифрованием счётчика, затем накладывается на текст через XOR.

```
CTR₁ = IV(8 байт) || 0x00×8
CTRᵢ = Add(CTRᵢ₋₁)         — инкремент по модулю 2⁸

Cᵢ = Pᵢ ⊕ truncate(AES_enc(CTRᵢ), |Pᵢ|)
```

- **Дополнение не требуется** — последний блок может быть короче 16 байт.
- Операция шифрования и расшифрования **идентичны**.
- IV задаётся 8 байтами (16 hex-символов) в `.env`.

## Внутреннее устройство алгоритма

### Структура одного раунда AES

```
Шифрование:                        Расшифрование:
AddRoundKey(K[0])                  AddRoundKey(K[Nr])
                                   InvShiftRows → InvSubBytes
for r = 1..Nr-1:                   for r = Nr-1..1:
  SubBytes                           AddRoundKey(K[r])
  ShiftRows                          InvMixColumns
  MixColumns                         InvShiftRows → InvSubBytes
  AddRoundKey(K[r])
                                   AddRoundKey(K[0])
SubBytes → ShiftRows
AddRoundKey(K[Nr])
```

### Параметры по вариантам ключа

| Вариант | Длина ключа | Слов Nk | Раундов Nr |
|---|---|---|---|
| AES-128 | 128 бит (16 байт) | 4 | 10 |
| AES-192 | 192 бит (24 байта) | 6 | 12 |
| AES-256 | 256 бит (32 байта) | 8 | 14 |

### SubBytes через аффинное преобразование

```
1. x' = gf_inv(x)        — мультипликативная инверсия в GF(2⁸)
2. y  = A·x' + c (mod 2) — аффинное преобразование над GF(2)
```

Неприводимый многочлен: `f = x⁸ + x⁴ + x³ + x + 1`.
